# Knowledge index

This index maps published sources used across the library. The first five sections were built on 2026-11-15 from a topic map written before any searching. Each topic was split into the questions a practitioner would ask. For each question, standards, foundational books, academic research, consulting firms, operator writing, vendor documentation and critics were all checked. The first pass found operator writing mostly through framework names, so it under-covered essays that reason from the problem without naming a framework. Later passes read those essays, listed as operator rows in each section. Operator accounts count as primary sources here, on a par with studies.

Use it three ways. Find the canonical source for a question. See how far the library's claims rest on each source. See what is still unread and why.

## How to read the columns

| Column | Values |
|---|---|
| Access | Free: readable without an account. Free account: a no-cost registration opens it. Metered: a few free articles, then a paywall. Paid: purchase or subscription. Library: academic database. Not found: no copy located |
| Read | Full: the whole text was read. Extracted: the full text is held locally and the passages the library uses were checked against it, without a read end to end. Part: some pages or chapters. Abstract: the summary or landing page only. Secondary: only others' summaries. Not reached: attempted without success |
| Used in | The file that relies on it, or "index" when listed here only. OMC operating model choices, SC structure choices, ODC org design case, PMS program management system, DR decision rights, PG planning and goals, SQL AI-assisted SQL, MT metric trees, QW query workflow, DB dashboards and maintenance, SR scenario response, FC financing choices, ROOM diligence room, TH talent and hiring, GA startup operations, GF finance checklist, GL legal checklist, GP people checklist, GT provider prices, WP workplace problem solving, SO sales operations, CSP customer success, MA matrix stakeholder alignment |

Several PDFs that the research tools could not open were later converted with a local text extractor. Those rows say Extracted unless they were read end to end. A free copy found on the author's site, a course page or the publisher's contents counts toward Read. Access still shows how the original is sold. Copies that appeared to be unauthorized uploads were not used.

## Conflicts found between sources

1. **Prosci success rates.** Secondary sources cite 88 and 82 percent. The 12th edition summary shows 88 percent for the global benchmark of 10,800 respondents and 82 percent for the U.S. subset, where the poor group had five respondents.
2. **Spotify paper disclaimer.** A researcher reported none. The 2012 paper itself calls the model a snapshot of a journey in progress.
3. **Two CISR "four operating models."** Ross 2005 classifies company operating models. Thorogood and Woerner 2025 classify IT operating models with different names.
4. **Reorganization success.** Figures run from 8 to about 66 percent by definition. See [the evidence table](../skills/organization-and-change/references/operating-model-choices-and-evidence.md#what-the-evidence-does-and-does-not-show).
5. **Text-to-SQL accuracy.** Leaderboards report 83 to 97 percent. An audit found annotation errors in about half of one BIRD subset, so leaderboard numbers overstate certainty.
6. **Goodhart's law.** The popular wording comes from Hoskin as cited by Strathern, not from Goodhart.
7. **The premortem's 30 percent.** Klein's article says prospective hindsight improves identification of causes by 30 percent. His co-authors later described the underlying 1989 result as about 30 percent more reasons generated.
8. **PMBOK 8 principles.** PMI lists holistic view, value, quality, accountable leadership, sustainability and empowered culture. One training firm published a different six. PMI's own list is used here.
9. **Project Oxygen.** Coverage from 2011 and 2013 lists eight manager behaviors. Google's current re:Work page lists ten.
10. **The 70 percent failure figure.** Beer and Nohria's 2000 article repeats it without a source. Hughes's 2011 review found no valid evidence for it.
11. **CEO span.** Rajan and Wulf report direct reports rising from about four to seven. Neilson and Wulf report about five to almost ten, counting a wider set of roles.
